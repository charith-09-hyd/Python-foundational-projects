# Python Foundation Projects

Welcome! This repository contains a collection of beginner-friendly Python applications built during my holidays before starting college. These projects helped me build a strong foundation in core programming logic, conditionals, and loops.

## 🚀 Projects Included

*   **Restaurant Billing System:** A console-based application to calculate bills, manage item totals, and generate clean receipts.
*   **Simple Calculator:** A functional tool handling basic arithmetic operations like addition, subtraction, multiplication, and division.
*   **Basic Survey Application:** A program designed to collect user inputs, process responses, and display survey summaries.
